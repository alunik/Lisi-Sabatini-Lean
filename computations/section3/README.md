# Section 3 computations in Magma

This is a standalone reproduction of the finite computations in Section 3 of
*Sylow synchronization in finite groups: The good case*. It checks the inclusive
range $5\leq n\leq40$ for both $S_n$ and $A_n$, the nilpotent-pair assertion for
$9\leq n\leq40$, and the five numerical anchor inequalities used for larger
degrees. The manuscript snapshot is Overleaf Git commit
`e7896fe09f180baba9298732eb9c92be0464b64c`.

Every assertion concerns all prescribed Sylow families, not just one tested
family. For $S_8$, the required Sylow $2$-intersection is inclusion-minimal of
order $2$; the script does not assert that it is trivial.

## Run

With Magma installed, run from the repository root:

```sh
cd computations/section3
python3 verify.py
```

The optional wrapper checks successful completion and the expected coverage.
To select a Magma executable and save its full output with a source-hash receipt:

```sh
python3 verify.py --magma /path/to/magma --output /path/to/receipt-directory
```

Python is not needed for the computations themselves:

```sh
magma -b run.m
```

A complete run ends with `SECTION3_PASS`, reporting 36 symmetric cases,
36 alternating cases, 64 nilpotent-pair cases, and 5 anchors. A process exit code
alone is not sufficient evidence of success. Saved runs are described in the
[verification record](../../verification/2026-09-23-section3/README.md).

The files have the following roles:

| File | Purpose |
| --- | --- |
| `run.m` | Coverage, numerical inequalities, and final assertions |
| `profiles.m` | Exact cycle profiles, rational bounds, and independent small-degree checks |
| `exceptions.m` | Exact conjugacy-class and double-coset certificates |
| `witnesses.m` | Explicit permutations for the double-coset certificates |
| `verify.py` | Optional execution and receipt wrapper |

All inequalities use exact integer or rational arithmetic. The witness lists
are fixed inputs whose properties are checked on every run. Magma's seed is
fixed; acceptance uses exact group calculations and assertions, with no
statistical test. No Lean installation is needed. Groups of degree greater
than 12 are handled by short polynomial calculations, rather than constructed
or enumerated.

## Why the checks prove the universal statements

For each prime $p$, fix two Sylow subgroups $P_p,Q_p$ of a finite group $G$.
For uniformly distributed $g\in G$, let $X_p(g)$ count the elements of order
$p$ in $P_p\cap Q_p^g$. If this intersection is nontrivial, then
$X_p(g)\geq p-1$. Writing $a_D=|D\cap P_p|=|D\cap Q_p|$ for each conjugacy
class $D$ of elements of order $p$ gives
$\Pr(P_p\cap Q_p^g\ne1)\leq\sum_D a_D^2/((p-1)|D|)$.
The equality of the class counts follows from Sylow conjugacy.

Thus a sum of these bounds strictly below $1$ gives one $g$ working for every
prime simultaneously, for any independently prescribed left and right Sylow
families. This includes the conjecture's choice $Q_p=P_p$. The factor
$1/(p-1)$ sharpens the element-count bound displayed in the paper.

### Cycle profiles

Let $A_k(X)$ record the elements of order dividing $p$ in a Sylow $p$-subgroup
$W_k$ of $S_{p^k}$, with exponent equal to the number of $p$-cycles. Starting
with $A_0=1$ and $|W_0|=1$, the wreath-product decomposition gives
$A_{k+1}(X)=A_k(X)^p+(p-1)|W_k|^{p-1}X^{p^k}$ and
$|W_{k+1}|=p|W_k|^p$.
The second term counts the elements with a nonidentity top permutation: the
condition that their $p$th power is $1$ determines one base coordinate from
the other $p-1$ coordinates.

For the base-$p$ expansion $n=\sum_k d_kp^k$, multiply
$\prod_k A_k(X)^{d_k}$. Its coefficient $a(n,p,j)$ counts the elements of
type $[p^j,1^{n-pj}]$ in a Sylow subgroup of $S_n$. That class has size
$C(n,p,j)=n!/(p^jj!(n-pj)!)$. The symmetric bound is consequently
$\sum_{j\geq1}a(n,p,j)^2/((p-1)C(n,p,j))$.

For $A_n$ at $p=2$, retain only even $j$; these classes do not split. For odd
$p$, the cost equals the symmetric cost. An order-$p$ class can split only
when $j=1$ and $n=p$ or $p+1$. Here a Sylow subgroup is cyclic, and its $p-1$
nonidentity elements divide equally between the two alternating classes.
Indeed, a generator of its power automorphisms acts on the nonzero residues
as a $(p-1)$-cycle and is odd, so the even normalizer induces the index-two
subgroup of power automorphisms.
The two half-sized classes therefore have the same total contribution as
the symmetric class. The script independently checks these formulas against
Magma's actual Sylow and conjugacy-class calculations for $5\leq n\leq12$,
including split classes.

These bounds suffice for $S_7,S_{11},S_{13},S_{15}$ and $S_{17},\ldots,S_{40}$,
and for every $A_n$ in the stated range except $A_8$.

### The matching refinement for $S_{14}$ and $S_{16}$

Put $m=n/2$. Each Sylow $2$-subgroup contains the group generated by the
transpositions of a perfect matching. For two prescribed Sylows, choose such
matching groups $E$ and $F$. Let $X$ count involutions in $P\cap Q^g$, let $Y$
count nonidentity elements in $E\cap F^g$, and let $T$ count common matching
edges. Then $1_{P\cap Q^g\ne1}\leq X-Y+T$: a nonidentity permutation belonging
to both matching groups has a common edge, by uniqueness of its disjoint
transpositions.

Since each matching group has $\binom mj$ elements of type $[2^j,1^{n-2j}]$,
this replaces the binary profile bound by
$\sum_j a(n,2,j)^2/C(n,2,j)-\sum_j\binom mj^2/C(n,2,j)+m^2/\binom n2$.
Adding the odd-prime costs gives a strict bound below $1$ at both degrees.

### Good double cosets for $S_9,S_{10},S_{12}$ and $A_8$

If a Sylow $2$-subgroup $P$ satisfies $P\cap P^g=1$, the entire double coset
$PgP$ consists of good conjugators and has size $|P|^2$. The script verifies
explicit representatives and uses Magma's double-coset canonical form to
check that their double cosets are distinct. It certifies respectively
7, 6, and 41 such cosets for $S_9,S_{10},S_{12}$. The resulting good mass
$k|P|^2/|G|$ exceeds the sum of the odd-prime bad bounds.

For $A_8$, one explicitly checked double coset already gives good mass
$64^2/20160=64/315$, which likewise exceeds the odd-prime cost. Sylow
conjugacy and translation of the uniform distribution make these bounds
valid for any prescribed pair of Sylow $2$-subgroups.

### Conjugacy-class certificates for $S_5,S_6,S_8$

Here the distribution of $g$ is uniform on a conjugacy class: cycle type
$[3,2,1^{n-5}]$ for $n=5,6$, and $[5,3]$ for $n=8$. For each prime the
script first computes the global minimum of $|P\cap P^g|$, using all double
cosets of $N_G(P)$ in $G$. It then computes exactly the proportion of the
chosen class where that minimum is not attained, using the weighted double
cosets $C_G(x)\backslash G/N_G(P)$.

| Group | Primes | Minimum intersection orders | Sum of bad proportions |
| --- | --- | --- | --- |
| $S_5$ | $2,3,5$ | $1,1,1$ | $7/10$ |
| $S_6$ | $2,3,5$ | $1,1,1$ | $5/6$ |
| $S_8$ | $2,3,5,7$ | $2,1,1,1$ | $191/336$ |

Conjugacy invariance of the sampling class makes each proportion independent
of the prescribed Sylow subgroup. The union bound therefore works for any
family $(P_p)$ in the conjecture. Minimum order among all intersections
implies inclusion-minimality, including the nontrivial binary intersection
in $S_8$.

### Nilpotent pairs

Every bound used for $n\geq9$ concerns uniform $g\in G$ and independently
prescribed pairs $P_p,Q_p$. If $H,K\leq G$ are nilpotent, their unique Sylow
$p$-subgroups lie in some $P_p,Q_p$. Simultaneous trivial intersections
$P_p\cap Q_p^g=1$ exclude every prime-order element from $H\cap K^g$.
Cauchy's theorem then gives $H\cap K^g=1$. This proves all 64 reported
nilpotent-pair cases without enumerating nilpotent subgroups.

## Numerical anchors and scope

The code evaluates the paper's majorants, without the cyclic improvement,
and checks
$M(40,2)<3/4$, $M(39,3)<1/25$, $M(40,5)<1/10000$,
$M(35,7)<1/2400$, and $M_{\mathrm{ev}}(40)<3/16$.
It also verifies the two final rational budgets
$3/4+1/25+1/10000+1/2400+1/1024<1$ and
$3/4+4/25+1/2500+1/600+1/256<1$.

These finite calculations do not verify the paper's infinite monotonicity
lemmas for $M(n,p)$ or $M_{\mathrm{ev}}(n)$, or the argument bounding the
infinite prime tail. Those remain mathematical arguments in the paper.
